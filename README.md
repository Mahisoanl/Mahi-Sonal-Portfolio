A responsive personal portfolio built with HTML, CSS and vanilla JavaScript. The project descriptions, skills, education and certifications are based on the résumé provided.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or use VS Code with Live Server.

## Deploy with GitHub Pages
1. Create or select the repository you want to use for this website.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. Wait for GitHub Pages to publish the site; use the URL shown in Pages settings.
6. Test the live site on desktop and mobile.

Official guide: https://pages.github.com/
